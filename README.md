這是高中時期[橘子蘋果程式學苑](https://orangeapple.co/)老師帶著在課堂上做的作品。雖然是這麼說，但是我在課堂上瘋狂地超前進度，結果多出了很多空閒時間，開始自己胡思亂想一堆新功能，還把所有圖像改成自己喜歡的樣子。最後的成品雖然一樣是塔防遊戲，但已經和原本的課綱「天差地遠」，老師也是讚譽有佳。<br>
操作方式、介面：<br>
畫面右上方是三種防禦塔，由左至右為傷害突出、射速突出、範圍突出。點擊圖示進入該塔的建造，遊戲自動暫停，此時點擊其他圖示可以切換，點擊原圖示可以取消。而使用chrome或是IE瀏覽器(其餘尚未經測試)時，還能以滑鼠滾輪在進行遊戲與三種防禦塔的建造共四個模式之間切換。<br>
三種防禦塔圖示下方為暫停/繼續按鈕，可手動控制。遊戲因各種原因自動暫停/繼續時，按鈕圖示也會跟著改變。<br>
再更下方有兩個量表，左方為玩家血量條(2X9，共九點血量)，遊戲地圖分四條岔路(敵人隨機選擇)，敵人到達扣除一點血量，血量歸零遊戲結束。右方為金幣，最大儲存9金幣，擊殺敵人獲得1金幣，升級或建造防禦塔消耗1金幣。<br>
左方為遊戲主要畫面，敵人上方為敵人血量條。游標移至敵人圖像上方顯示該敵人等級，遊戲自動暫停。游標移至防禦塔上方顯示該防禦塔等級與範圍，若其正在鎖定敵人亦會標示，遊戲自動暫停。此時點擊升級該防禦塔。<br>
若使用者試圖將防禦塔蓋在路線上，或是使用者試圖建造/升級防禦塔但金幣為零，皆會有警告訊息。
